# 🏥 Rede PriceHub — 3 Vitrines Farmacêuticas Independentes

O projeto contém **3 sites completos de farmácia**, cada um com **layout exclusivo**, **identidade visual própria** e **tabelas de preços distintas** para os **10 medicamentos mais vendidos do Brasil**.
